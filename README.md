# Whisper App

**Фраза уже прозвучала? Нажми `F8`.** Whisper App добавит к записи последние 5 секунд системного звука. Нажми `F8` ещё раз, и русская расшифровка окажется в буфере обмена.

Утилита для Windows, когда нужно вытащить цитату из видео, реплику из звонка или кусок подкаста. Источник записи один: системный звук с устройства вывода по умолчанию, захваченный через WASAPI loopback.

## Запуск на Windows

Понадобятся **Windows x64**, **Python 3.12 x64** и Git. Открой PowerShell и выполни:

```powershell
git clone https://github.com/ReGo2552/whisper-app.git
cd whisper-app
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe whisper_app.py
```

При первом запуске приложение скачает модель и токенизатор с Hugging Face. Дождись статуса **«Готов»**. После загрузки файлов распознавание работает локально, а захваченный звук хранится в оперативной памяти.

## От звука к тексту

1. Включи звук и нажми `F8` или **«Начать запись»**. Ползунок задаёт, сколько звука взять до нажатия, от 0 до 30 секунд. По умолчанию стоит 5.
2. Нажми `F8` снова или выбери **«Остановить»**. Дождись сообщения **«Скопировано в буфер»** и вставь результат через `Ctrl+V`.

**«Живой текст при записи»** показывает черновик по последним 30 секундам. После остановки приложение распознаёт всю запись, включая захваченный звук до старта. **«Поверх окон»** оставляет расшифровку на виду, пока ты смотришь видео или слушаешь звонок.

## GPU и CPU

Приложение сначала пробует CUDA (`float16`) и при ошибке инициализации переключается на CPU (`int8`). На CPU живой текст выключается по умолчанию. Его можно включить перед записью.

Для NVIDIA GPU нужны драйвер и библиотеки CUDA 12 и cuDNN 9. Подробности есть в [требованиях faster-whisper](https://github.com/SYSTRAN/faster-whisper#gpu).

Чтобы сразу запустить на CPU, выполни в PowerShell:

```powershell
$env:CUDA_VISIBLE_DEVICES = '-1'
.\.venv\Scripts\python.exe whisper_app.py
```

## Если звук не захватывается

- Проверь, что видео или звонок воспроизводится через устройство вывода по умолчанию в Windows.
- Если переключил наушники или колонки, нажми **«Обновить звук»** между записями.
- Если `F8` недоступна, кнопка записи в окне работает и без глобальной клавиши.

Распознавание выполняет [faster-whisper](https://github.com/SYSTRAN/faster-whisper) с [моделью Podlodka Turbo в формате CTranslate2](https://huggingface.co/bzikst/faster-whisper-podlodka-turbo) и [токенизатором оригинальной модели](https://huggingface.co/bond005/whisper-podlodka-turbo).
